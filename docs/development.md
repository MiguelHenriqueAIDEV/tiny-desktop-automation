# Development Notes

Tiny Desktop Automation was developed through an iterative AI-assisted workflow using Codex Sol.

## Workflow

1. Define the automation behavior
2. Describe the requirement through prompts
3. Generate or modify the implementation
4. Test the application on Windows
5. Identify incorrect behavior
6. Refine the prompt or implementation
7. Test again
8. Validate the final behavior
